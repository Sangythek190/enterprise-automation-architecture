Product Management Work

What it took to design and operate this automation system

🔍
Workflow Discovery
Mapped every manual step in the order-to-fulfillment pipeline. Identified 7 handoff points where orders stalled or dropped between teams.
📝
Automation Design
Designed 30+ automations across 6 categories. Each automation has defined triggers, actions, tags, and audit trails so every state change is traceable.
🔄
Branching Logic
Built decision trees for credit vetting (approve/decline), order routing (CPE vs Proposal Builder), and payment failure handling (auto-cancel + notify).
💰
Billing Reconciliation
Created audit automation that compares platform state against Contract Billing. Catches billing drift before it becomes a revenue leak or partner dispute.
🕑
Retention Engineering
Designed retention workflow: order cancelled → retention team notified instantly → sales task created with 2-day due date. No cancellation goes unnoticed.
🔨
Self-Healing Design
Built self-healing automations: if a product activation fails, the system deactivates and re-activates automatically. Prevents support ticket escalation.
